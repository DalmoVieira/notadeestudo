# Nota de Estudo

Aplicação web para organização e consulta de anotações de estudo.

## Objetivo

O projeto foi criado para centralizar conteúdos, anotações e materiais de estudo em uma interface simples e acessível.

## Funcionalidades

- Organização de notas por assunto;
- Consulta rápida dos conteúdos;
- Interface simples para uso em navegador;
- Estrutura preparada para futuras melhorias.

## Tecnologias

- HTML;
- CSS;
- JavaScript.

## Como executar

1. Clone o repositório;
2. Abra o arquivo `index.html` no navegador; ou
3. Execute o projeto usando uma extensão de servidor local, como o Live Server do VS Code.
